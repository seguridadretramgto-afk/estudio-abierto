# Estudio Abierto · Ciudadanía digital en acción

Ambiente de aprendizaje colaborativo en línea del **Reto 4** del módulo *Tecnología e innovación en la sociedad del aprendizaje* (UVEG).

**Equipo 5:** Ana Lucía Resendiz Hernández · Cecilia Salinas Soto · Elda Beatriz Piña González · Jaime Demetrio Retana Ramos · Juan Andrés Zapata Martínez
**Asesor:** Guillermo Alejandro Zaragoza Alvarado · Noviembre de 2026

## Qué es

Un espacio de trabajo en equipo para estudiantes de tercer semestre de bachillerato. El proyecto es una campaña de ciudadanía digital para la comunidad escolar: brief, pieza gráfica accesible, plan de difusión y coevaluación con rúbrica.

El ambiente tiene trece pantallas: portada, cómo funciona, objetivos, contenidos, matriz de planificación, herramientas, configuración, las tres actividades, sala de equipo, evaluación y galería.

## Cómo se usa

Es un archivo único de HTML, CSS y JavaScript. No requiere instalación, base de datos ni conexión: se abre en cualquier navegador actual y funciona también en teléfono. Se navega con el menú lateral o con las flechas del teclado.

## Publicación

Este repositorio se publica con GitHub Pages a partir de `index.html` en la raíz.
Versión de consulta del ambiente; el aula real vive en Moodle, con cuenta institucional.
